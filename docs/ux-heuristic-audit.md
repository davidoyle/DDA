# Implemented UX heuristic audit

| Heuristic | Problem | Impact | Fix | Severity | Fix type | Implementation status |
|---|---|---|---|---|---|---|
| System status | Form/search gave weak progress feedback | Uncertain state | Loading, result count, pending, success and error announcements | High | Interaction | Complete |
| Real-world language | Capability language was hidden behind generic rendering | Slow recognition | Decision-led headings and evidence instruments from approved copy | High | Content/UI | Complete |
| User control | Overlays could strand focus | Keyboard failure | Escape, close controls, focus trap and trigger focus return | Critical | Accessibility | Complete |
| Consistency | Public and tool tokens overlapped | Visual regressions | Scoped `.site-shell` palette and retained tool tokens | High | Engineering | Complete |
| Error prevention | Contact could submit incomplete or twice | Rework/duplicates | Required validation and disabled pending button | High | Form | Complete |
| Recognition over recall | Flat nav hid capabilities | Higher memory load | Wide capability menu, breadcrumbs, active states, contents links | High | IA | Complete |
| Efficiency | Search only matched titles | Missed routes | Full 20-page title/topic/description/content index | Medium | Search | Complete |
| Minimalist design | Home risked becoming a service catalogue | Executive overload | Purpose, insights, proof, concise CTA | High | Template | Complete |
| Error recovery | Form errors lacked consolidated recovery | Failed inquiry | Focused error summary, field links, preserved values | Critical | Form | Complete |
| Help/documentation | Legal/accessibility paths were peripheral | Trust gap | Strong information footer and cross-linked utility family | Medium | IA | Complete |
| 5-second value clarity | Positioning was not consistently prominent | Poor comprehension | Purpose H1/dek and decision-first capability openings | Critical | Content/UI | Complete |
| Audience relevance | Sector relevance could become microsites | Fragmentation | Context retained inside capability and work copy | Medium | IA | Complete |
| Obvious high-intent next step | CTA labels varied | Lower conversion clarity | “Discuss a decision” as global primary action | High | UI | Complete |
| Trust without overclaiming | No logos/testimonials were available or appropriate | Risk of invented proof | Evidence modules and verified instruments provide credibility | Critical | Trust | Complete |
| Low executive cognitive load | Long pages lacked scan support | Slower evaluation | Templates, descriptive headings, contents nav, readable measure | High | Layout | Complete |
