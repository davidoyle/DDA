# DDA public design system

The public shell uses Civic Navy + Lichen, an institutional sans-serif stack, paper surfaces, 1px rules and square geometry. Type carries hierarchy: 40–82px fluid H1, 30–50px H2, 22–32px H3 and 17px/1.75 body. Containers are 1,240–1,296px; sustained reading is about 790px.

Spacing follows 4, 8, 12, 16, 24, 32, 48, 64, 80, 96 and 128px. Components include the dark header, What-we-do mega-menu, mobile full-screen navigation, search dialog, breadcrumb, hero geometry, evidence sequence, editorial cards, selected-work stories, related/contact band, form and multi-column footer. Public template classes are `template-home`, `template-capability-hub`, `template-capability-detail`, `template-about`, `template-insights-hub`, `template-article`, `template-selected-work`, `template-contact`, and `template-utility`.

Motion is progressive enhancement: opacity and no more than 28px translation. Reduced-motion removes transition and transform. Focus is a 3px amber outline; statuses always include text. Interactive controls target approximately 44px where practical (not stated as a blanket WCAG minimum).
