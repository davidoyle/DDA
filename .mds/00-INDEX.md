# DDA website handoff index

This package contains finished copy for 20 public webpages, the page-mapped UI and functional specifications, and the Humanizer record. Give the entire folder to the implementing Codex instance so route, copy, design, and existing-tool requirements stay together.

## Start here

1. Read [Functional specification](./00-FUNCTIONAL-SPEC.md) for runtime behaviour, page joins, navigation, search, and acceptance tests.
2. Read [UI specification](./00-UI-SPEC.md) for the Deloitte-like DDA shell, responsive layouts, components, accessibility presentation, and restrained motion.
3. Import the 20 page files below as the approved public copy. Do not add source-history, proposal-status, or drafting commentary to the public pages.
4. Read [Humanizer notes](./00-HUMANIZER-NOTES.md) only as an editorial record. It is not website copy.

The functional specification takes precedence for behaviour. The UI specification takes precedence for presentation. The page files supply the words. Existing deployed source remains authoritative for diagnostic tools already on the website.
