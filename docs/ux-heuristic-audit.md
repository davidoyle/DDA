# UX heuristic audit and implemented fixes

| Heuristic | Problem → impact | Implemented fix | Severity | Type |
|---|---|---|---|---|
| Visibility of status | Form/search state was easy to miss → uncertainty | Live result count, pending label, success/error regions | High | Accessibility |
| Match to real world | Generic services language → poor recognition | Approved decision, deadline, dependency and instrument language | High | Content |
| User control | Overlays could strand focus → keyboard failure | Escape, close control, focus trap and restoration | Critical | Accessibility |
| Consistency | “Our Thinking” and Contact labels varied → hesitation | Insights and Discuss a decision used in primary chrome | Medium | Content |
| Error prevention | Duplicate and incomplete submission → frustration | disabled pending submit and pre-submit validation | High | Technical |
| Recognition | Deep pages lacked parent context → orientation cost | hierarchical breadcrumbs and on-page outline | High | Structural |
| Flexibility | Search only matched titles → missed routes | title, description and topic index for all 20 pages | Medium | Technical |
| Minimalism | Flattened prose hid priorities → executive load | family templates, cards, narrow articles, generous rhythm | High | Visual |
| Error recovery | Generic failure risked data loss → re-entry | preserved values, linked summary and field errors | High | Accessibility |
| Help | Next step was vague → conversion friction | decision-specific contact bands and disclaimer | Medium | Content |
| Five-second clarity | Positioning competed with sections → unclear offer | outcome-led hero and two direct routes | Critical | Structural |
| Audience relevance | No rapid sector cues → bounce | approved planning, labour, fiscal and project examples | High | Content |
| Obvious next step | “Learn more” patterns → ambiguity | descriptive route links and Discuss a decision | High | Content |
| Trust without overclaiming | Trust depended on assertion → scepticism | evidence modules and named artifact types; no outcomes invented | Critical | Content |
| Low executive load | One renderer gave every block equal weight → scanning cost | nine page-family treatments and restrained homepage | High | Visual |
