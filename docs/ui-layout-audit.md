# UI layout audit

Implemented a fixed-width dark institutional header, wide capability menu, editorial dark home opening, readable article measure, persistent deep-page context, evidence sequences, selected-work proof rhythm, contact close and substantial secondary-navigation footer. The shell caps at 1,296px and reflows to one column below 1,024px; 320px overrides prevent CTA and metadata overflow. Interactive tables retain a labelled local scroll region rather than forcing page overflow. Diagnostic pages retain their own existing component hierarchy; new palette tokens are scoped to `.site-shell`.
