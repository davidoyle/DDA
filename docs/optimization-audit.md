# Optimization audit

Public copy remains in the approved Markdown files and is imported once. A typed JSON manifest supplies runtime routes, metadata, navigation/search and build-time prerender/sitemap generation. Diagnostic applications remain lazy route chunks. The production step writes route-specific meaningful HTML with unique title, description, canonical and OpenGraph fields so public content does not depend entirely on client execution. Decorative artwork is SVG and requires no bitmap payload. Future licensed photos should use responsive AVIF/WebP, explicit dimensions and lazy loading below the fold.
